# Website PCCC

Website về Phòng cháy chữa cháy (PCCC).

## Bắt đầu

```bash
git clone https://github.com/hungphuedu-maker/website-pccc.git
cd website-pccc
```

## Quy trình làm việc với Git

1. Tạo nhánh mới cho mỗi thay đổi: `git checkout -b ten-nhanh`
2. Commit thay đổi: `git add . && git commit -m "Mô tả thay đổi"`
3. Đẩy lên GitHub: `git push -u origin ten-nhanh`
4. Tạo Pull Request trên GitHub để gộp vào nhánh chính.
